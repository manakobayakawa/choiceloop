# ChoiceLoop 実装と残る設定

追加提供された統合バンドルとプラグイン0.2.0を正本にしました。既存Siteを維持し、凍結済み25ケースとベースライン・再測定の原本を追加型の移行で保持します。

評価名は Information sufficiency。既存のローカル規則評価は7/25 → 7/25、変化0です。顧客の選択・ライブAI推薦・予約成功は不明です。同じ内容の再実行であり、生成した案の効果とは表示しません。質問・順序・凍結fingerprintは変更しません。

元のPxxx・24件案は別の提案用ワークスペースとして残します。25件を24件へ置換しません。Pilot5とMVP25には同じrun_idの別ベースラインがあるため、実験ID・出典パスとハッシュで区別します。

英語の5画面で、正確な質問、保存済みの評価記録、証拠の引用と確認範囲、承認待ちの案、条件を合わせた比較を確認できます。取込はサーバーで検証し、重複、質問変更、基準や証拠の不一致を拒否します。原本・null・失敗・出典・時刻・ハッシュを維持します。

保存はSites D1、原文・スクリーンショットはR2です。ユーザー別に分離し、認証・同一Origin・冪等キー・更新競合をサーバーで確認します。大きな状態は複数のD1行へ分割し、localStorageを共有DBとして使いません。承認は資産版・ハッシュ・操作に結び付け、編集で無効にします。

ローカルで保存・再読込・Worker再起動後の保持、R2読戻し、所有者分離、取消、改ざん拒否を検証します。本番の認証・保存・正式MCP接続は非公開デプロイ後に別途確認します。

実行可能な推論・検索・ブラウザー・常駐ワーカーは未確認です。Runは無効で、成功を装いません。役割指示の取込とAI実行は別です。既存25件の結果を新規AI実行とは表示しません。
