# ChoiceLoop 実装・統合メモ

この版は機能を持つ実験ワークスペースです。ライブ検索の結果は初期状態で0件です。100件の合成シナリオ、提案段階の24ケース計画、9件の提供済み公開サイト監査を読み込みます。監査は今回アプリが実行した検索ではありません。

## 保存と認証

- Sites標準Vinext / Cloudflare Workers。`.openai/hosting.json` にD1 `DB`、R2 `BUCKET` を宣言。
- D1の `workspaces` と `workspace_chunks` に、実験・シナリオ・観察・診断・改善案・承認・ジョブ・比較・監査の版付き集約を分割保存。生回答が増えても1行に集中させません。`commands` に冪等キー、入力ハッシュ、応答、リビジョンを保存。試作版のワークスペース上限は24MBです。
- リビジョンの条件付き更新と同一D1バッチ内の受領記録により、競合した保存は409になり、完了した入力の再送を重複させません。
- Sitesの認証済みユーザーIDごとに保存先を分離。APIの書込、ファイル、MCPはサーバーで認証を必須にします。認証なしのローカルプレビューは資料を読むだけです。
- localStorageには実験を保存しません。D1/R2ローカル検証はホストされたDBの検証とは別です。
- R2には入力コマンドの内容ハッシュ付き原文と、認証済みアップロードを保存。アップロードは最大5MB、ファイル形式を制限し、保存後に読取確認。ファイルは同じユーザーだけ取得できます。

## 実行の境界

モデル推論、検索、ブラウザーワーカー、バックグラウンド実行は既定で利用不可です。ボタンから実行したように見せる処理はありません。

使える経路は **ChatGPT-assisted / manual handoff** です。計画を明示的に凍結し、3質問のタスクパケットを出力し、実際の回答をJSONで取り込みます。観察は検証後に保存され、無効な行は理由付きで隔離されます。正しい行の保存は維持されます。手動ジョブには保存済みの進捗・失敗・キャンセル・回数制限付き再開があります。閉じたタブで処理が進むとは表示しません。

任意のOpenAI APIアダプターは `lib/openai-adapter.mjs`。`OPENAI_ADAPTER.md` を参照。明示的なモデルとSitesのサポートされた秘密情報設定が必要です。ChatGPTの契約はAPI認証ではありません。実API接続が未検証なので、アプリの自動Runは無効です。APIアダプターを使うには、別途、許可された小さな呼出しを検証してからジョブ実行経路へ結線する必要があります。

## 測定の扱い

- `LIVE_AI_SEARCH`、`CONTROLLED_SIMULATION`、`BOOKING_PATH_CHECK`、`ILLUSTRATIVE_SAMPLE` を区別。
- 公開サイト監査は evidence に保存し、ライブ指標に数えません。テスト用namespaceとSAMPLEも集計外です。
- 正確な質問とSHA-256、計画版、実行時刻、元の回答、provider/product等を保持。失敗・不明値はnullのまま保存します。
- 表示順・明示された選好順位・言及・推薦・仮想選択・予約先への到達を分離。
- 互換比較には同じモード、モデル・製品、質問、反復、設定、プロトコルが必要。シミュレーションはさらに候補・証拠・評価基準・変更しない対照のハッシュを必要とします。
- 未公開の案にライブ検索の変化を帰属させません。シミュレーションから実顧客の転換率や売上を主張しません。
- 元のpersona、旧計画・重み、原本全体をlegacy/source_documentsに保持。旧スコアを自動流用しません。

## 改善案と承認

事実ごとの証拠リンクを必須にします。承認はサーバーの認証済みユーザー、時刻、資産版・ハッシュ、許可した操作を記録します。自由記述のattestationは確認文として保存し、別人を承認者にしません。編集は新しい版を作り、過去の承認を無効にします。

承認可能なのは `controlled_test` と `export` です。外部公開のゲートや実店舗サイトの更新は実装していません。V004に関わる未解決の事実は承認をブロックします。予約・テーブル確保・個人情報入力・支払は行いません。

## 非公開展開とMCP

Siteは非公開・未公開で作成。ユーザーの指定に従い、非公開デプロイの明示承認まで公開操作を行いません。Sitesの本番URLは、非公開であってもデプロイ後に発行されます。内部QAの `terminal.local` はユーザー向けプレビューURLではありません。

`/mcp` はSites仕様の `server/discover`、`tools/list`、`tools/call` に対応。get_experiment / save_observations / save_diagnosis / save_intervention / start_run / get_run_status / compare_runsを同じユーザー別DBへ接続します。承認ツールは公開しません。start_runは実行基盤が未検証ならblockedになります。

Sitesが非公開デプロイ時に作る標準プラグインを再利用します。別のMCPプラグインを手動作成していません。既存skills-only ChoiceLoopは変更していません。統合・一本化のサポートは未確認で、IDを推測した接続はありません。MCPの遠隔接続は、認証された書込と読戻しに成功するまで未検証です。
