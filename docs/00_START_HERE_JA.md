# ChoiceLoop — 並行作業パック

作成日：2026-10-23。既存ChoiceLoop Pluginの作成とは独立した準備資料です。プラグインの作成・公開・接続・自動検索はこのパックでは実施していません。

## まず開くもの
**06_baseline_runbook_JA.md**：最初の3問を各2回実測する手順。

## 3人で並行する分担案
| 担当 | 先に進める作業 | 完成物 |
|---|---|---|
| Mana | シナリオと意思決定上の問い、デモ構成を確認。07を別チャットに渡してUI準備 | 入出力が決まった画面、英語デモの流れ |
| メンバーA | 06に沿って独立した検索を実行。結果を03の形式で保存 | 回答全文・出典・日時付きベースライン |
| メンバーB | 05の事実と実際に登場する競合を検証。未確認項目を分ける | 根拠台帳、改善仮説、店主への確認事項 |

これは分担の提案であり、チームで確定済みの担当ではありません。3人とも同じ質問を重複実行する場合は、独立実行・繰り返しとして記録し、結果を混ぜず残してください。

## 元データからの変更を明示
旧READMEには優先12件とありますが、実データは13件で、全件がBudget-consciousでした。旧holdout 25件も全件Location convenienceです。元ファイルは変更せず、新しい実験計画を別ファイルにしました。
新計画は、開発・最終検証のそれぞれに予算、雰囲気、予約、立地を3件ずつ含めます。5つの顧客区分・5つの目的も各群で2〜3件ずつ含めます。地域顧客の代表性や統計的精度は保証しません。
別チャットで旧計画によるテストがすでに行われていれば、その結果を新計画として扱わず、元の実験バージョンを保ってください。
