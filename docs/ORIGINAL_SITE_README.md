# ChoiceLoop · Café Athena

Don't just optimize for being found. Optimize for being chosen.

Functional English experiment workspace built on ChatGPT Sites/Vinext, native D1 and R2. Five connected views cover preserved synthetic scenarios, manual run handoffs, source-grounded diagnosis, versioned approvals, and strict paired comparisons. No live results are preloaded.

Start with `docs/IMPLEMENTATION_JA.md`, `docs/INTEGRATION_AND_MIGRATION.md`, `docs/OPENAI_ADAPTER.md` and `docs/TEST_RESULTS.md`.

## Development

Use the installed Sites workflow and its project setup/install/build helpers. The project ID in `.openai/hosting.json` is canonical. Never create a duplicate Site.

Run domain fixtures with `node --test tests/*.test.mjs`. Build using the installed Sites `scripts/build-site.mjs`. D1 migrations are generated by `npm run db:generate`; apply to local preview using the documented starter command. Do not replay already applied migrations. Deployment uses Sites and requires the user's explicit private-deployment approval for this project.

Secrets belong only in supported Sites secret storage. `.env*`, `.dev.vars*`, runtime state and test-generated private artifacts are ignored. There is no client API key field, no localStorage database and no automatic reservation/publication action.
